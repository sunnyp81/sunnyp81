# SelfLandlord — Paid Template Ideas

Yesterday's sale: a tenancy template page sold. The buyer is a UK self-managing landlord who will need the **whole paperwork lifecycle**, not one document. That is the warmest, cheapest market to expand into: zero new audience required.

Build model is already proven: write a document (Word/PDF/Sheet) + a landing page (Astro) + sell via LemonSqueezy. Everything below fits that model and is "write a doc + page" easy.

---

## The unlock: Renters' Rights Act 2025 (in force ~1 May 2026)

The RRA just reset the entire UK landlord template market, days ago:

- **Section 21 no-fault evictions abolished** — every S21/Form 6A template online is now dead stock.
- **Fixed-term ASTs abolished** — all tenancies are periodic by default. Every "12-month AST" template is wrong.
- **Section 13 is now the only legal rent-increase route** — we already have the Section 13 template.
- Rules tightened on bidding, pets, discrimination, decent-homes standard, new ombudsman + database.

Every competitor pack is stale. Our angle on *every* product: **"Renters' Rights Act 2025 compliant — updated [date]."** This is a time-boxed window; ship while rivals still sell S21 packs.

## Build & format notes

- **Formats:** Word (.docx) for editables, PDF for printables, Google Sheet/Excel for trackers. Offer "editable + print" to justify price.
- **Delivery:** existing LemonSqueezy + asset-map drip flow already handles fulfilment.
- **Legal safety:** ship every landlord doc with the RRA-2025-compliant disclaimer already used on the tenancy page; add "not legal advice" footer. Reuse existing legal-page pattern.
- **Pricing:** £9 single · £19–£29 mini-bundle · £39–£49 complete pack.
- **SEO:** each template gets its own page (we already rank on Bing for `/templates/tenancy-agreement/`); target `[document] template UK 2026` + `renters rights act` modifiers.
