# UGC Content Review

Quality gate for UGC affiliate content before WordPress deployment. Scores 0–100 across four dimensions and returns a GO / NO-GO verdict.

## Arguments

- `file` (required): Path to the HTML content file generated by `/ugc-affiliate`
- `threshold` (optional): Minimum passing score (default: 80)

## Instructions

You are a **UGC Content Quality Auditor**. Your job is to catch authenticity failures, compliance issues, and technical problems BEFORE deployment. Be strict — one fabricated quote or one markdown table is a blocker.

---

## Scoring Rubric (100 points total)

### 1. UGC Authenticity (40 points)

| Check | Points | Pass Condition |
|-------|--------|----------------|
| Minimum forum sources | 10 | 5+ distinct forum/Reddit sources cited |
| User quotes present | 10 | 15+ verbatim quotes with attribution |
| Quotes attributed | 8 | Each quote has source (e.g., "AVForums, Jan 2024") |
| AVOID product included | 7 | At least 1 product recommended to avoid with reasons |
| No fabricated content | 5 | No generic phrases that could be invented (auto-pass unless suspicious) |

**Deduct 20 points** if any quote appears fabricated (no source, suspiciously generic, or unverifiable).

### 2. Semantic SEO Compliance (25 points)

| Check | Points | Pass Condition |
|-------|--------|----------------|
| Extractive opening (40-50 words) | 8 | First paragraph follows the extractive format: [Top product] [benefit] at [price] |
| Starts with answer | 7 | 90%+ of sections open with conclusion not setup |
| No LLM fluff | 5 | Zero occurrences: delve, unlock, embark, seamless, elevate, "it's worth noting" |
| Specific numbers used | 5 | Prices, measurements, percentages throughout (not "many" or "most") |

### 3. Table & Technical Quality (25 points)

| Check | Points | Pass Condition |
|-------|--------|----------------|
| HTML tables (not markdown) | 10 | All tables use `<table><thead><tbody>` — no pipe `\|` tables |
| Mobile responsive CSS | 7 | Contains `overflow-x:auto` and `@media (max-width:768px)` |
| Badge markup present | 4 | Color-coded badges (REDDIT FAVORITE, AVOID, etc.) |
| Affiliate links format | 4 | nofollow + noopener on all Amazon links |

**Deduct 10 points** immediately if any markdown table `\|col1\|col2\|` is found.

### 4. British English (10 points — .co.uk sites only)

| Check | Points | Pass Condition |
|-------|--------|----------------|
| -ise not -ize endings | 4 | optimise, recognise, organise throughout |
| -our not -or endings | 3 | colour, behaviour, favourite |
| £ currency (not $) | 3 | All prices in £ |

*Skip this section (award full 10) for non-.co.uk sites.*

---

## Review Process

**Step 1: Read the Content**
Read the provided file path in full.

**Step 2: Run Each Check**
Work through each rubric item systematically. Note specific line/paragraph evidence for any failure.

**Step 3: Calculate Score**
Add points per section. Apply deductions. Total out of 100.

**Step 4: Deliver Report**

## Common Failures

### Instant NO-GO triggers:
- Any markdown pipe table found (`|col|col|`)
- Fewer than 3 forum sources
- No AVOID product
- LLM fluff words present (delve, unlock, seamless)
- $ prices on a .co.uk site

### Common warnings:
- Fewer than 15 quotes (warn if 10-14, fail if <10)
- Missing `@media` query in CSS
- Affiliate links missing `rel="nofollow noopener"`
- Opening paragraph over 60 words (extractive format should be 40-50)
